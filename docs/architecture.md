# 架构

项目维持单 `app` module，按职责分为：

- `platform`：`LauncherApps` 应用目录/启动、图标 LRU 缓存、Home 角色、系统设置入口与包变化监听。
- `data`：Room 保存应用偏好、UTC 日桶、增量游标、会话解析状态、事件去重指纹和排序快照；DataStore 保存主题。
- `domain`：无 Android 依赖的衰减评分、稳定排序和会话提取。
- `ui`：Compose + ViewModel + StateFlow，Composable 只消费不可变状态并回传用户动作。

应用入口以 `userSerial + ComponentName` 形成稳定 ID；统计以用户/包聚合。多启动入口在全部应用中保留，动态常用区按包选择确定的代表入口，显式固定仍按入口保存。

系统事件采集在 IO 线程中执行。查询带两分钟重叠窗口，事件指纹采用唯一主键防止重复；新增事件、日桶聚合和游标/跨批状态在同一 Room 事务中提交。授权为空或暂不可读时不删除旧数据。进程恢复时从持久游标继续。

排序快照单独持久化，因此重启不会随机换位。固定/排除、卸载和手动重排属于显式安全更新；常用统计持续累积，但不逐次点击移动首页图标。
